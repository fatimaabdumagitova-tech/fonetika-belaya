# Фонетический разбор (белая версия)

Интерактивный тренажёр для начальной школы: фонетический разбор слова по образцу 3 класса —
ударение, слоги, звуки столбиком, характеристика звуков, подсчёт букв и звуков.
Белый фон и крупный шрифт — удобно показывать на доске, видно с задних парт.
